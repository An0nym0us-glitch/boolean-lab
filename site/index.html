What's inside

Built for a school computer lab

BooleanLab installs without admin rights, never needs the internet, and explains each mistake so the student can fix it.

Components

ANDORNOTNANDNORXORXNORSwitchConst 0/1LEDOutput

Every gate except NOT takes 2 to 8 inputs. Planned for later:

AddersMUX/DEMUXFlip-flopsClock

Editing

  • Snap-to-grid moves, selection boxes, arrow-key nudging
  • Rotate R, duplicate with wiring Ctrl+D
  • Zoom with Ctrl+wheel, pan with Space+drag
  • Undo and redo for every edit

Simulation

  • F5 Run, Shift+F5 Stop, Ctrl+F5 Reset
  • Wires turn green for 1 and grey for 0
  • Unconnected inputs show ? in orange
  • Feedback loops are marked red and explained

Wiring rules

Connect an output to an input. Each input takes exactly one wire, and an output can feed as many inputs as you like. If a student breaks a rule, the app says which one and why.

Projects

  • Open, save and recent files in the .blab format, which is plain JSON
  • Drag a file onto the window to open it
  • Damaged files are repaired and the app lists what it fixed
  • Half adder and full adder examples included

Look and feel

Light and dark themes. Every icon and gate symbol is drawn as a vector, so it stays sharp on high-DPI screens and projectors. Press F1 for the shortcut list.

Under the hood · C++17 · Qt 5.15

A simulator that can't get stuck

Each simulation pass makes one trip over the circuit graph, in O(components + wires) time. The engine depends only on Qt Core and is tested on its own.

  1. Find feedback loops

    Tarjan's strongly-connected-components algorithm finds combinational loops. A loop has no single stable answer, so the app names the gates in it and gives them unknown outputs instead of iterating forever.

  2. Evaluate in topological order

    Kahn's algorithm orders everything else so each gate is evaluated exactly once, after all of its inputs are known.

  3. Propagate unknowns like real logic

    An AND with a 0 input outputs 0 and an OR with a 1 input outputs 1, even when another input is unconnected.

Free download

Install it on every PC in the lab

Every push to the repository builds a Windows installer, BooleanLab-Setup-0.1.0-x64.exe, and a portable folder. CI installs, runs and uninstalls the installer before it publishes either one.

  • Standard setup wizard with Start Menu entry and uninstaller
  • Install for me only works without admin rights
  • Optionally opens .blab files with BooleanLab
  • Bundles its own runtime, so nothing else needs installing
